# AC/DC Fan Website 🎸

## Opis projektu
Strona fanowska zespołu AC/DC stworzona jako projekt zaliczeniowy
z przedmiotu Projektowanie Stron WWW.

## Technologie
- HTML5 (znaczniki semantyczne)
- CSS3 (Flexbox, Media Queries)
- Google Fonts
- Font Awesome
- JavaScript (Web API)
